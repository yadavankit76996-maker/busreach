About BusReach

Public transport accessibility field project

Back to dashboard

Purpose

BusReach is a student field-project website designed to help people discover bus stops in the study area, check published timing information and find nearby stops when location permission is granted.

How to use the dashboard

  • Search by bus stop name, road, landmark, area or route information.
  • Select Use my location and allow browser location access to sort mapped stops by distance.
  • Open directions for a stop with coordinates.
  • Use Suggest a bus stop to send a missing location or correction. Suggestions are reviewed by an administrator before publication.

Data and reliability

BusReach only displays records published by the project administrator. A schedule entry should include its information source and the date it was checked. A scheduled time is not a live arrival prediction. Live estimates should only be shown if a reliable real-time data source is actually connected.

Distances are approximate straight-line distances from the device location, not walking distance or travel time. Map and location features require an internet connection; browser location requires permission and a secure hosted website or localhost.

Technologies used

  • HTML: page structure and forms.
  • CSS: layout, responsive styling and readability.
  • JavaScript: search, distance sorting, form validation and dashboard behaviour.
  • Supabase: hosted PostgreSQL database, authentication and image storage.
  • Leaflet and OpenStreetMap: interactive map display and map tiles.
  • GitHub Pages: static website hosting, if used for deployment.

Administration and privacy

Only authorized admin accounts can publish stops and timings. Public users can send suggestions but cannot publish them directly. Use only appropriate public place photos; avoid photos containing identifiable people, private information or vehicle registration details where possible.

Project limits

This dashboard does not automatically know where a bus is. Arrival times depend on the verified schedule data entered by the admin or on a real-time transport feed if one becomes available. Do not rely on this student project for emergency travel decisions.
